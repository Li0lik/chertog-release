# chertog-release

Model files for [chertog](https://github.com/Li0lik/chertog), published as release assets that chertog downloads and verifies by sha256.

| release | contents | licence |
|---|---|---|
| `models-bge-reranker-t2plus-int8-ext-v1` | BAAI/bge-reranker-v2-m3 exported, int8, vocabulary trimmed (T2+), external data | Apache-2.0 (BAAI) |

Each release carries `SHA256SUMS`, `LICENSE` and `NOTICE.md` (source, changes, reproduction).
